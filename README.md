# 📖 Group Meet：小排聚會信息

每週小排聚會的 **信息** 與 **讀經進度（聖經恢復本）**，手機打開就能讀。

- 首頁 `index.html`：本次聚會（分頁：📄 信息／📖 聖經進度）＋ 往期信息列表（可搜尋）
- 管理 `admin.html`：輸入管理密碼後直接編寫每週信息（不用再做 PDF）、設定讀經進度、修改或刪除

## 設計與動態

- **第一屏**：深藍夜景、金色月亮和海浪（仿每週信息的封面），中間立著一張玻璃卡，卡上亮著 GROUP MEET、本週讀經範圍和日期。夜景上是本次聚會的日期、標題、副標題，和「讀信息」「聖經進度」兩顆按鈕。
- **開場**：白色畫面上一個很淡的 GROUP MEET 和 0→100% 的數字；資料載好後夜景從畫面中央長出來，卡片的光閃亮，文字一個字一個字浮現。
- **往下捲**：畫面先停住，卡片轉正、邊緣發亮、填滿白光並放大到超出螢幕，白色就變成內容頁（信息／聖經進度分頁、往期信息）。往回捲會倒著播。手機大約多捲一個螢幕，電腦一個半。
- **導覽列**：固定在最上面，在夜景上是白字，進到內容後變成深色字；電腦版中間有「信息／聖經進度／往期」。
- 有滑鼠的裝置會有一個圓形游標；系統設定「減少動態效果」時不播開場和穿越卡片的動畫，改成簡單淡入。
- 動畫用 [GSAP](https://gsap.com/) 3.15 與 ScrollTrigger（從 jsDelivr 載入），英數字用 Geist 字體、中文用 Noto Sans TC／Noto Serif TC（Google Fonts）。GSAP 載不到時，網站會改成不帶動畫的靜態版面，內容照常可讀。
- 夜景和卡片都是用 CSS／SVG 畫的，沒有圖片檔。顏色、字體等設計變數在 `style.css` 最上面；動畫的時間和比例在 `motion.js` 最上面。

## 功能

| 頁面 | 說明 |
|---|---|
| 📄 信息 | 依管理頁填的內容排成網頁：壹 讀經（含禱讀經節）、貳 詩歌、參 信息選讀、肆 問題研討。以前上傳過 PDF 的週次仍會顯示 PDF |
| 📖 聖經進度 | 直接列出本週要讀的恢復本經文（一節一行，可調字級）；多章時上方有章節快速跳轉；每章讀完可打勾「已讀」（記在自己的手機上） |
| 往期信息 | 以前每週的信息都保留，依年份排列，可用標題、書卷、日期搜尋 |
| 管理 | 新增一週時，日期會自動帶「上週＋7 天」，讀經進度會自動接續上週（可以改）；禱讀輸入「可 6:50~51」按「帶入經文」自動填入恢復本經文；右邊（手機在下方）即時預覽；沒發布前會自動存草稿 |

### 編寫信息的格式

- **詩歌**：每節開頭寫節數（`1`、`2`…）；副歌那一節第一行寫 `（副）`；節與節之間空一行。
- **信息選讀**：`◆` 開頭的一行是小標題；整段用（ ）括起來的是出處（例如 `（馬可福音生命讀經，191~196 頁。）`），會靠右；段落之間空一行。從 PDF 或網頁貼上時，斷行會自動接回。
- **問題研討**：一行一題，前面的「一、」「1.」可寫可不寫，網站會自動編號。

「本次聚會」＝今天以後最近的一次聚會；如果都已經過了，就顯示最近的一次。

## 資料存放

資料存在 Supabase 專案 **PaulWu722's Project**（與年終愛筵同一個專案）：

- 資料表 `gm_messages`（每週一筆；信息內容存在 `content` 欄位）、`gm_settings`（管理密碼）、`gm_file_tickets`（上傳許可）
- 檔案空間（Storage）bucket `groupmeet`：公開讀取，只收 PDF，單檔上限 50MB
- 訪客不能直接讀寫資料表；上傳和刪除 PDF 一定要有正確的管理密碼

資料庫已經建好了。要在其他 Supabase 專案重建，把 [`supabase/schema.sql`](supabase/schema.sql) 貼到 SQL Editor 執行即可（可重複執行），再把網址和 publishable 金鑰填進 [`config.js`](config.js)。
`config.js` 的兩個值留空時是**示範模式**：資料只存在自己的瀏覽器，密碼 1234。

### 修改管理密碼

Supabase → SQL Editor 執行：

```sql
update public.gm_settings
  set value = encode(sha256(convert_to('新密碼', 'UTF8')), 'hex')
  where key = 'admin_password_sha256';
```

## 讓網站上線（GitHub Pages）

1. GitHub repo → **Settings → Pages** → Source 選 `Deploy from a branch`，選 `main` 分支、資料夾 `/ (root)`。
2. 網址會是 `https://paulwu722.github.io/Group-meeting/`（管理頁：`…/Group-meeting/admin.html`）。

## 更新網站後

改了 `.css` 或 `.js` 之後，請把 `index.html` 和 `admin.html` 裡每個檔名後面的 `?v=...` 換成新的值（例如日期），手機才會抓到新檔案，不會顯示舊的。
